# aicatlog

An agent-first interface to environment, harness and Skills resources.

Discover a capability, inspect its schema, retrieve the relevant source and perform
the task through a shared CLI and SDK. Structured manifests supply navigation;
session-managed tgrep indexes accelerate full-text search.

Built with Bun, TypeScript and Incur. TOON and JSON output, progressive help,
OpenAPI/Fetch and a minimal Skills fork. No MCP.

Implementation and usage documentation are being built with the R2 milestones in
`SPEC.md`. Run `bun install` to prepare the development dependencies.
