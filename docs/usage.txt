Metadata navigation does not load every Skill body. A qualified ID identifies one
resource even when names repeat. Sources and cached structural indexes are distinct.
Use index refresh after changing the resource corpus outside the owner commands.
For declared context resources, context inspect returns current headings, line
ranges, a source digest and inline link targets without loading linked documents.
Use read --section with a unique heading label/slug or an inspected heading:<line>
selector. Repeated headings require an explicit selector; topic mappings take
priority. An index may return valid=false with diagnostics while preserving its
sections and links for repair. The operation does not return the complete body.

Declare document_role/context_format as context_index/llms-txt-v2 for indexes or
prompt_context/markdown for context leaves. Only an undeclared file named llms.txt
uses filename classification. A workflow.llms.txt suffix alone does not assign a
role. Other roles, including output_template, remain ordinary catalog metadata.
The scanner supports top-level ATX/Setext headings, fenced code and inline links;
reference-style links, HTML blocks and nested container headings are outside its
navigation contract. No link expansion or target-existence check is performed.

settings.resource_aliases may contain {"retired:guide":"docs:guide"}. Each value
must be an existing qualified ID. Aliases do not create extra resource rows or
native Skill files. registry check reports invalid mappings; exact real IDs retain
priority and a successful alias lookup reports canonical ID and resolution details.
END_TOPIC discover

BEGIN_TOPIC search
aicatlog find "literal text" --content --scope <scope-id> --json
aicatlog find "regular.*expression" --content --scope <scope-id> --regex --json
aicatlog find "just edited" --content --scope <scope-id> --fresh --json

Content search uses a session-managed tgrep backend. The response reports its route,
freshness, scope and any fallback. Indexed results are eventually consistent; use
fresh searches for current absence and edit checks. Exact source reads bypass indexes.
Index status does not renew a lease. Stop releases the caller's lease; workers exit
when no active leases or queries remain. The default idle lease is 15 minutes.
END_TOPIC search

BEGIN_TOPIC mutate
Skills install/update/remove/sync/normalize and harness bootstrap prepare plans.
aicatlog apply --plan <prepared-plan-file>

Apply checks the prepared registry, source and target fingerprints. Changed targets
require a new plan. The run directory retains backups, a journal and a receipt.
Atomic replacement currently supports macOS and Linux. Keep --state on the same
filesystem as source-changing targets; cross-device plans fail before replacement.
Use --recover only for the exact interrupted plan with an exited writer.
External source owners are reported explicitly; generic installation does not replace
an owner kit's workflow or Hook registrations.
END_TOPIC mutate

BEGIN_TOPIC api
The Bun SDK exports createAicatlog(options, extensions), call, serve and fetch.
CLI and SDK commands share validation and implementation. Fetch returns JSON envelopes
and exposes /openapi.json. It does not start an HTTP service or expose MCP.
Structured CLI input uses --input with JSON, @file or stdin. JSON values override
corresponding positional/options. Global runtime configuration remains separate.
--full-output selects the result envelope; read selects source content. Use structural
pagination, not token slicing, to keep machine output intact.
